## Applied Education Program Evaluation: Multiple Membership Modeling

This repository contains selected, anonymized code from a real K–12
program evaluation project. The goal of the analysis was to estimate
the impact of an educational intervention on student GPA while
accounting for non-random assignment and complex teacher–student
clustering.

### Key Methods
- Propensity score matching with balance diagnostics
- Multiple-membership random effects models
- Longitudinal and administrative education data
- Equity-relevant covariates (attendance, discipline, FRPL context)

### My Role
I led data integration, matching design, model specification,
diagnostics, and interpretation of results.

### Why This Matters
This analysis informed program improvement decisions and provided
defensible impact estimates for stakeholders operating in real-world
school settings.
